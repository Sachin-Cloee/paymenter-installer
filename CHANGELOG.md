# Changelog

All notable changes to this project will be documented here.

The project intends to follow [Semantic Versioning](https://semver.org/) after the first tagged release.

## Unreleased

### Added

- GitHub Actions checks for Bash syntax and ShellCheck
- Structured bug, feature, and compatibility issue templates
- Pull request template
- Contributing and security guidance
- Release and promotion checklist

### Changed

- Reorganized the README around installation, trust, compatibility, and support
- Added status badges and a clearer project-support call to action

- Interactive Paymenter installation for Ubuntu and Debian
- Local and remote MariaDB support
- Optional administrator creation
- Nginx and Let's Encrypt configuration
- Scheduler and queue-worker setup
- Existing-installation backups
- Domain-change utility
- Post-installation validation
